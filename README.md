This entry takes a fresh angle: instead of complaining about the meeting itself, it lets the calendar fight back. One small act of defiance — declining a recurring invite a single time — and the scheduling tool answers with the one event nobody wants on their calendar. The joke lands on the last word, where a routine chore turns into a career threat. The calendar is not a passive tool here; it is the opponent, and it wins.

## Run it

```bash
python3 main.py
```

This writes the one-liner to `/output/entry.txt` and prints it to stdout.
